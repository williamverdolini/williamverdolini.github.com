Abstract

Another todo list application…but this is in CQRS+ES sauce!
This is my training journey into Command Query Responsibility Segregation (CQRS) + Event Sourcing (ES) patterns.

Current implementation (2026)

The articles in this section describe the original 2014–2015 application. That .NET Framework web application and its command/query stacks have been retired. The project has since been rebuilt as a separate training application with a .NET 10 API, an event-sourced domain, a SQL Server event store and read projection, and a standalone Angular 22 frontend served by Nginx.

Docker Compose starts the complete stack. From the modern directory in the repository, run docker compose --env-file .env.example up --build. The UI is served at http://localhost:4200. See the current source and setup guide.

Legacy data is not imported automatically. The legacy event exporter and modern importer are retained for a deliberate import. The source links in the articles below point to the historical implementation captured in this repository revision.
