2026 update: This series documents the original 2014–2015 .NET Framework and NEventStore implementation. The articles remain as a historical account; the old Web UI and command/query stacks have since been retired.

The training application now has a separate modern track: a .NET 10 API and event-sourced domain, SQL Server event store and read projection, and a standalone Angular 22 UI served by Nginx. Docker Compose runs the full stack. See the modern implementation and its setup guide.

Legacy data is not imported automatically; the legacy event exporter and importer remain available for a deliberate import. Code links in this series are pinned to the historical source revision.
